Detailed Description

PLACEHOLDER movement for wave testing only. Leonardo's enemy AI replaces this; WaveEncounter does not depend on it. The ship steers along a short route of waypoints on the gameplay plane with a capped turn rate and turn acceleration, so direction never changes instantly. Every route ends with a straight descent: below Straight Below Z the ship stops turning, so nothing turns near the player. Reactions are limited: a one-off shift towards the player's lane, or (for some classes) a flank pass beside the player's last observed position that tracks for at most Tracking Seconds. Reactions are shrunk if they would close the last escape lane (see LargestGap). Per-wave settings come from the TestDifficultyProfile entry for the enemy's wave. All positions are in the parent's space (the encounter's Spawn Parent), so if that parent rides a moving rail rig the routes, lanes and safety heights move with it. With no parent this is plain world space.
