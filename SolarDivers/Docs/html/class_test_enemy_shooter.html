Detailed Description

PLACEHOLDER attacks for the test enemies (not Leonardo's AI or Taha's weapons). Each armed ship attacks once, only when TestAttackDirector allows it, and always with a warning:

  • Gun: the ship glows orange and shows an aim line that follows the player's predicted position (limited lead), the line locks Aim Lock Seconds before firing, then a single shot or a short burst flies straight along it. Interceptors fire one quick shot with a little more lead; fighters fire bursts.
  • Rocket: the ship pulses red with a red lock line for the rocket warning time, then launches one homing rocket (TestHomingRocket: limited turn rate, speed and homing time, so it can be dodged). The role comes from the wave's TestDifficultyProfile entry and the ship's class / formation slot.
