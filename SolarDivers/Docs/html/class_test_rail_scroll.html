Detailed Description

PLACEHOLDER rail motion for the integrated demo: moves this rig (camera, player, spawn origin, bounds space) forward at a constant speed, standing in for Abel's LevelCamera until its keyframe movement is finished. Speed 0 = static (the default). Lets us check that spawns, bounds and enemy routes follow a moving rig. ResetToStart is wired to R. Runs before other scripts and syncs physics after moving: a CharacterController child (Abel's player) keeps its own physics position and would otherwise be left behind, because this project does not auto-sync transforms. The real rail camera will need the same Physics.SyncTransforms() call (or to move the player explicitly).
