Detailed Description

Integrated demo only: holds the frame rate at a fixed value while the scene is running. Abel's PlayerController currently moves by Speed per frame (not per second), so without a fixed frame rate the ship would be faster on high-refresh monitors. Remove this once that movement is scaled by Time.deltaTime. Restores the previous settings when disabled (leaving Play mode or unloading the scene).
