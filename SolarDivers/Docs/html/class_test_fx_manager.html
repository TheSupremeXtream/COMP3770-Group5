Detailed Description

TEMPORARY effects and sound for the wave scenes until the team has an audio system (Ronit has none in the repository yet); not the team's audio/VFX system. Spawned effects are parented here so a restart can remove them. Sounds are edited CC0 recordings from a TestSoundBank: several variants per sound, never the same variant twice in a row, small pitch changes, a voice pool with per-sound limits, separate weapons / impacts / explosions / engines / warnings volumes, and explosions that duck each other (and duck under attack warnings) instead of stacking up. Everything is stopped on restart and when Play mode ends. Engine and flyby sounds live in TestFlightAudio.
