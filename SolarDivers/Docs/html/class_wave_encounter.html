Detailed Description

Runs a list of enemy waves in order. Spawning only: enemy movement/AI lives on the enemy prefabs. An enemy stops counting toward its wave when it is destroyed/disabled, leaves the encounter bounds, or is force-removed by the clear timeout. "Cleared" means every wave finished; it does not mean every enemy was destroyed (see AllEnemiesDestroyed). FailEncounter() ends it without victory.
