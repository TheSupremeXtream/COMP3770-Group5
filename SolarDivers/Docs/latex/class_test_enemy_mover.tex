\doxysection{Test\+Enemy\+Mover Class Reference}
\hypertarget{class_test_enemy_mover}{}\label{class_test_enemy_mover}\index{TestEnemyMover@{TestEnemyMover}}


PLACEHOLDER movement for wave testing only. Leonardo\textquotesingle{}s enemy AI replaces this; \doxylink{class_wave_encounter}{Wave\+Encounter} does not depend on it. The ship steers along a short route of waypoints on the gameplay plane with a capped turn rate and turn acceleration, so direction never changes instantly. Every route ends with a straight descent: below Straight Below Z the ship stops turning, so nothing turns near the player. Reactions are limited: a one-\/off shift towards the player\textquotesingle{}s lane, or (for some classes) a flank pass beside the player\textquotesingle{}s last observed position that tracks for at most Tracking Seconds. Reactions are shrunk if they would close the last escape lane (see Largest\+Gap). Per-\/wave settings come from the \doxylink{class_test_difficulty_profile}{Test\+Difficulty\+Profile} entry for the enemy\textquotesingle{}s wave. All positions are in the parent\textquotesingle{}s space (the encounter\textquotesingle{}s Spawn Parent), so if that parent rides a moving rail rig the routes, lanes and safety heights move with it. With no parent this is plain world space.
