\doxysubsection{Detailed Description}
Integrated demo: makes the Rail\+Rig (camera, player, boundaries, spawns, bounds space) follow a path object that Abel\textquotesingle{}s \doxylink{class_level_camera}{Level\+Camera} moves along its Key\+Frames. His component is used as-\/is; this adapter only adds what the encounter needs on top of it: 


\begin{DoxyItemize}
\item it runs before other scripts and calls Physics.\+Sync\+Transforms() after moving the rig, so the player\textquotesingle{}s Character\+Controller (Abel\textquotesingle{}s \doxylink{class_player_controller}{Player\+Controller}) rides along instead of being left behind (auto-\/sync is off);
\item Reset\+To\+Start (wired to R) puts the path and the rig back at the start, since \doxylink{class_level_camera}{Level\+Camera} has no reset. The rig lags the path by at most one frame (it reads the position \doxylink{class_level_camera}{Level\+Camera} set last frame). 
\end{DoxyItemize}
