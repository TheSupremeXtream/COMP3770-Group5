\doxysection{Test\+Fx\+Manager Class Reference}
\hypertarget{class_test_fx_manager}{}\label{class_test_fx_manager}\index{TestFxManager@{TestFxManager}}


TEMPORARY effects and sound for the wave scenes until the team has an audio system (Ronit has none in the repository yet); not the team\textquotesingle{}s audio/\+\+VFX system. Spawned effects are parented here so a restart can remove them. Sounds are edited CC0 recordings from a \doxylink{class_test_sound_bank}{Test\+Sound\+Bank}: several variants per sound, never the same variant twice in a row, small pitch changes, a voice pool with per-\/sound limits, separate weapons / impacts / explosions / engines / warnings volumes, and explosions that duck each other (and duck under attack warnings) instead of stacking up. Everything is stopped on restart and when Play mode ends. Engine and flyby sounds live in \doxylink{class_test_flight_audio}{Test\+Flight\+Audio}.
