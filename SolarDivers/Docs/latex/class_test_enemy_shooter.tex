\doxysubsection{Detailed Description}
PLACEHOLDER attacks for the test enemies (not Leonardo\textquotesingle{}s AI or Taha\textquotesingle{}s weapons). Each armed ship attacks once, only when \doxylink{class_test_attack_director}{Test\+Attack\+Director} allows it, and always with a warning: 


\begin{DoxyItemize}
\item Gun: the ship glows orange and shows an aim line that follows the player\textquotesingle{}s predicted position (limited lead), the line locks Aim Lock Seconds before firing, then a single shot or a short burst flies straight along it. Interceptors fire one quick shot with a little more lead; fighters fire bursts.
\item Rocket: the ship pulses red with a red lock line for the rocket warning time, then launches one homing rocket (\doxylink{class_test_homing_rocket}{Test\+Homing\+Rocket}: limited turn rate, speed and homing time, so it can be dodged). The role comes from the wave\textquotesingle{}s \doxylink{class_test_difficulty_profile}{Test\+Difficulty\+Profile} entry and the ship\textquotesingle{}s class / formation slot. 
\end{DoxyItemize}
