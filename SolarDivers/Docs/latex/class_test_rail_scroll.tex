PLACEHOLDER rail motion for the integrated demo: moves this rig (camera, player, spawn origin, bounds space) forward at a constant speed, standing in for Abel\textquotesingle{}s \doxylink{class_level_camera}{Level\+Camera} until its keyframe movement is finished. Speed 0 = static (the default). Lets us check that spawns, bounds and enemy routes follow a moving rig. Reset\+To\+Start is wired to R. Runs before other scripts and syncs physics after moving: a Character\+Controller child (Abel\textquotesingle{}s player) keeps its own physics position and would otherwise be left behind, because this project does not auto-\/sync transforms. The real rail camera will need the same Physics.\+Sync\+Transforms() call (or to move the player explicitly).
