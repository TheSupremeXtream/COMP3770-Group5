TEMPORARY test-\/scene HUD for the wave prototype. Not the game\textquotesingle{}s UI (Ronit owns UI); delete it once the real HUD listens to \doxylink{class_wave_encounter}{Wave\+Encounter}\textquotesingle{}s events. Built at runtime with u\+GUI (built-\/in font, no extra assets). Layout is authored at 1920x1080. Readability: draw it through a UI-\/only camera with post-\/processing off (or leave UI Camera empty for Screen Space -\/ Overlay), so anti-\/aliasing, bloom and vignette never touch the text. Text is pixel-\/snapped and never scales below Minimum Scale, so it stays legible in a small Game view. Hull/\+wave panel (top-\/left), wave banner (top-\/centre), controls (bottom-\/left), result panel (centre), detailed counters behind Tab (top-\/right), red edge flash and pip pulse when the player is hit.
